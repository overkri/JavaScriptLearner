# 02 · Функции и замыкания

**Цель модуля:** понять функции как значения, замыкания и разницу обычных и стрелочных функций.
Файлы модуля: `src/utils/id.js`, `src/utils/functional.js`, `src/playground/closureQuiz.js`, `src/playground/thisArrowQuiz.js`.

## Функции — значения первого класса

Функцию можно присвоить переменной, передать аргументом и вернуть из другой функции. Функция, принимающая функцию, — функция высшего порядка; переданная функция — callback. Объявление `function greet() {}` поднимается (hoisting), а `const greet = () => {}` доступно только после строки объявления.

## Параметры

- Значение по умолчанию: `function createTask({ priority = 'medium' } = {})`; срабатывает при `undefined`, но не при `null`.
- Rest: `function sum(...numbers)` собирает остаток аргументов в настоящий массив.
- `arguments` есть только у обычных функций; это array-like объект, а не массив. В стрелках его нет.

## Замыкания

Замыкание — функция вместе с лексическим окружением, в котором она создана. `createIdGenerator(prefix = 'task')` хранит счётчик в `let` внутри фабрики и возвращает функцию: у каждого генератора свой независимый счётчик, снаружи он недоступен. `createCounter(start)` так же прячет состояние и отдаёт `increment`, `decrement`, `reset`, `value`.

## Утилиты TaskFlow

`src/utils/functional.js` реализует:

- `once(fn)` — только первый вызов, сохраняет `this` и аргументы.
- `debounce(fn, ms)` — вызов через `ms` после последнего; trailing edge, есть `cancel()`.
- `throttle(fn, ms)` — не чаще раза за интервал; leading edge.
- `memoize(fn, keyFn = JSON.stringify)` — кэш по аргументам, есть `clear()`.
- `pipe(...fns)` — слева направо, первый получает все аргументы; `compose(...fns)` — справа налево.
- `curry(fn)` — накапливает аргументы до `fn.length`; `partial(fn, ...preset)` фиксирует начало.
- `tap(fn)` — побочный эффект и возврат исходного значения; `not(predicate)` — инверсия для `filter`.

## Стрелки и this

У обычной функции `this` определяется вызовом: `obj.method()` — `this === obj`, а вызов без объекта или передача метода в callback теряют `this`. Стрелка своего `this` не имеет и берёт его из места создания. У стрелки также нет `arguments`, `prototype`, и её нельзя вызвать через `new` — будет `TypeError`. В `createLexicalThisCounter()` стрелка внутри `run()` видит `this` объекта и увеличивает его `count`.

## Java → JS

| Java                          | JavaScript                                 |
| ----------------------------- | ------------------------------------------ |
| `Function<T,R>`, `BiFunction` | функция — обычное значение                 |
| lambda                        | стрелочная функция `x => x * 2`            |
| effectively final capture     | замыкание над `let`, значение можно менять |
| SAM-интерфейс                 | callback без интерфейса                    |
| method reference              | `fn` или `() => obj.method()`              |
| Stream pipeline               | `pipe` / `compose`                         |

## Типичные ловушки

1. Цикл с `var` и `setTimeout`: все колбэки видят одну переменную и печатают `3, 3, 3`; `let` создаёт привязку на итерацию → `0, 1, 2`.
2. Передали метод как callback (`setTimeout(obj.run, 0)`) — `this` потерян; исправляют `bind`, стрелкой-обёрткой или `() => obj.run()`.
3. У стрелки нет собственных `this`/`arguments`; `new (() => {})` бросает `TypeError`.
4. `curry` опирается на `fn.length`: параметры по умолчанию и rest уменьшают длину, и каррирование сработает не так, как ожидается.
5. `debounce` сбрасывает таймер при каждом вызове: важен последний вызов, а не первый; стрелочная обёртка внутри теряет `this`, поэтому нужна обычная `function` и `apply`.
